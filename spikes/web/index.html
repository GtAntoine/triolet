Triolet web spike

Five icons ported from the original generator, rendered by @triolet/core. Change the three colours, hover the icons, tab to the buttons. Generated by pnpm spike:web.

1. Motion: hover, keyboard focus of a parent, play()

Hover an icon. Tab to a button: the icon inside plays when the button gets keyboard focus. "Play all" adds the class triolet-play.

2. Colours set on a block: own filters and shared filters

Each dashed block sets its own --triolet-*. On the left of each block the icon has its own filters; on the right it uses the filters shared by the page. Expected: the flat colours follow the block in both; the relief shadow of the shared one keeps the page colours (a filter reads its colours where it is defined).

3. The three relief tiers, 96 to 16 px

"by size" is what the library picks: full relief from 40 px, compact relief (major shapes only, stronger) from 24 to 39 px, flat under 24 px. The other rows force one tier at every size, to compare.
